# 音频附件助手（实验版）

适用于能运行 Tampermonkey 兼容用户脚本的浏览器，安装 qianqian-audio-attach.user.js 后重新打开 ChatGPT。

1. 让一起听插件生成 15 秒 WAV，并把短期 HTTPS 下载链接显示在回复里。
2. 点击页面右上方“添加音频附件”，确认当前聊天中最新链接。没有自动找到时粘贴插件给的链接。
3. 脚本下载 WAV，尝试通过页面已有文件选择入口加入附件。确认附件卡片上传完成后自己发送。

不读取账号凭据、不自动发送、不后台循环、不改音乐服务。它只访问 cove.lumi.org.cn 的随机短期 WAV 地址，不保存链接。不打开任意远程 URL，也不使用 ChatGPT 私有上传 API。

本地只完成语法检查；尚未在用户的手机浏览器验证。ChatGPT 页面 DOM、脚本沙箱及文件上传限制可能导致添加失败，脚本不会把触发 change 事件当成上传成功。若入口无法定位或没有附件卡片，继续用正常的附件上传，不重复假报成功。它不能强制模型支持音频。
